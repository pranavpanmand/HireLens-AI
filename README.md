# Career Compass AI

AI-powered career platform with resume parsing, job aggregation, and a mock interview simulator.

## Tech Stack
- MongoDB
- Express.js
- React
- Node.js
- Vite
- TailwindCSS
- shadcn/ui

## Features
- AI Cover Letter Generator
- Mock Interview Simulator
- Resume Parser & Builder
- JSearch/Adzuna Job Aggregator
- Real-time Job Alerts
- Advanced Analytics
